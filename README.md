## 🚀 Getting Started

### Prerequisites

* Node.js 19.9.0 or higher
* npm 9.6.3 or higher

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Open:

```text
http://localhost:7777
```

## 📦 Deployment
